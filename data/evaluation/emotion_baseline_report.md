# Phase 6 rule-based emotion baseline — evaluation report

Generated by `objective_evaluation.evaluate_emotion` against the real, gold-labeled
(`emotion.provenance == "source"`), single-sentence subset of
`data/evaluation/{dev,test}.jsonl`. Multi-sentence gold examples are
excluded: the pipeline emits per-sentence emotion, and REDv2's label
covers the whole original (possibly multi-sentence) tweet, so a fair
per-sentence comparison isn't possible for those without further work.

Format follows objectives.md's "Recommended Evaluation Report Format".
Thresholds in `preprocess/emotion.py` (`MIN_EVIDENCE_WEIGHT`,
`MIN_TOP_SHARE`, `NEUTRAL_VALENCE_BAND`, ...) were inspected against `dev`
only, per objectives.md's acceptance criterion for this phase; `test`
numbers below are reported as produced, unmodified afterward.

**Updated after eval-set scaling** (`data/evaluation/README.md`'s Tier
1+2): the gold-labeled subset grew from 8 dev / 7 test to 99 dev / 92 test
— Tier 2's REDv2 sampling specifically targets real gold-emotion rows, so
this is now a large enough sample for the numbers below to mean something,
not just an indicative pilot reading. The rule baseline was **not**
re-tuned against the larger set — same thresholds as before, applied
unchanged; the drop in macro F1 compared to the 8/7-example pilot reading
reflects a truer picture of baseline performance at real scale, not
regression.

## Known limitations

- **`neutral` F1 is 0.000 at this scale, not just low-sample noise**: with
  19/15 real neutral-gold examples now available, the pattern from the
  8/7-example pilot is confirmed rather than explained away — see the
  dedicated `neutral`-vs-`unspecified` note below, it's structural, not a
  coverage gap.
- **Lexicon coverage**: NRC EmoLex Romanian (Google-Translate-derived) only
  covers ~3,883 emotion-bearing words. Several test misses are pure
  coverage gaps (e.g. "înspăimântătoare" isn't in the lexicon at all).
- **Translation noise causing genuine ties**: some words carry
  contradictory category tags from the translation process (e.g. "trist"
  = sad also tagged "anger"; "uimitor" = amazing tagged both "joy" and
  "surprise"). A tie for the top category is treated as ambiguous
  (`unspecified`) rather than arbitrarily picking one — this improves
  precision on confident predictions but reduces coverage, visible in the
  test-split numbers (many "unspecified" predictions instead of wrong
  guesses).
- **No contextual/compositional understanding**: "Când cineva îmi spune o
  minciună ... ajung la culmea furiei" (gold: angry) ties anger/sadness at
  equal lexicon weight — a genuine limitation of word-level lookup without
  syntax-aware composition, not a bug (verified by inspection, not fixed
  by further threshold tuning, since that would mean tuning on `test`).
- **No gold valence/arousal/intensity** in the evaluation set (only
  categorical emotion), so those aren't scored here, per objectives.md's
  own conditional ("if reference ... are available").
- **`neutral` is rarely predicted**: by construction, a sentence with zero
  lexicon matches has no valence signal to evaluate the "near-neutral
  valence" branch against, so it defaults to `unspecified` rather than
  `neutral` — defensible under objectives.md's own definition (`neutral`
  requires evidence *supporting* a neutral reading; zero evidence is
  exactly the `unspecified` case), but means genuinely neutral sentences
  with no emotion words currently read as `unspecified`, not `neutral`.

## Decision

Baseline established and honestly measured — not a target to beat, a
reference point for the trained classifier in objectives.md Phase 7 to
justify its added complexity against.

## Bugs found and fixed while measuring this (not test-set tuning)

Two real defects surfaced by looking at `dev.jsonl` predictions, both
general/principled fixes (not numeric threshold nudges), applied before
the numbers above were produced:

1. Sentence-level mean valence/arousal was being averaged from *every*
   word with a VAD entry (~16k common words, mostly emotionally neutral),
   diluting genuine signal from the one actually-emotional word in a
   sentence. Fixed: only fold in VAD scores from words that also cast a
   categorical vote.
2. A tied top category (e.g. "uimitor" -> joy/surprise, equal weight) was
   resolved arbitrarily by insertion order via `max()`. Fixed: an exact
   tie is now treated as ambiguous (`unspecified`).
